隐私

  • 本地只保存出口 IP、位置、时区与设置。
  • 不会读取浏览历史、Cookie、账号或页面内容。
  • 向第三方发出的请求仅用于查询当前连接的 IP / 地理信息。
  • 不修改 navigator.language。

Chromium 限制（请读）

  • 能完全做到：MAIN world 覆盖 geolocation（含 watchPosition 推送）、Intl 默认时区、Date 本地时间方法；按 IP 缓存；多源地理 API 容错。
  • 近似做到：页面内联脚本在 document_start 仍可能短暂看到真实时区（通常数十毫秒内被纠正）。Web Worker / 页面自己的 Service Worker 收不到 content script。
  • 做不到：注入 chrome://、Edge 商店、PDF 查看器；在不使用 debugger 的前提下改浏览器界面时区；从 v2rayN 读取节点名。
