环境诊断

判断 IP / Geo / Timezone / WebRTC / DNS / Locale 是否互相矛盾。 中文语言、中文字体、Windows 都不是泄漏。本页是扩展页，Intl 不受 MAIN world patch； 网页环境来自已打开的 http(s) 标签。Patch 自检是 best-effort，不是安全证明。

DNS 探测使用第三方服务 bash.ws 与 ipleak.net（接口可能变化；失败显示 unknown，不影响核心同步）。 成功结果缓存约 15 分钟；超时 / 全源失败约 60 秒后可重试。出口 IP 变化立即失效。 不发送网页 URL、浏览历史、Cookie 或账号。Cloudflare / Google / Quad9 / NextDNS 等全球公共 DNS 无法仅凭地区判断泄漏。
